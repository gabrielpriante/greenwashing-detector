# Contributing to Greenwashing Detector

Thank you for your interest in contributing! This project is being built by a student in my free time as a learning exercise and awareness tool. I welcome thoughtful contributions, corrections, and suggestions.

## About This Project

This is an educational tool created to help raise awareness about greenwashing in corporate marketing. It's intentionally kept simple and maintainable. The goal is to provide a useful starting point for exploring environmental language patterns, not to be a comprehensive or definitive solution.

## Ways to Contribute

I appreciate contributions in these areas:

### 1. Term Additions and Corrections

- **Add greenwashing terms**: If you've encountered misleading environmental language not in our database, please suggest it
- **Correct existing terms**: If a term is miscategorized or should be removed, let me know
- **Add sources/rationale**: Help document why specific terms are problematic with references to guidelines (FTC, ISO, etc.)

### 2. Documentation Improvements

- Fix typos or unclear explanations
- Add examples or use cases
- Improve installation or usage instructions
- Translate documentation (if you're interested in making this accessible to non-English speakers)

### 3. Code Improvements

- Bug fixes
- Performance improvements
- Better error handling
- Code quality improvements (while keeping it beginner-friendly)

### 4. Educational Content

- Add examples of real-world greenwashing
- Share resources about environmental standards
- Suggest improvements to explanations

## How to Contribute

### For Small Changes

1. Open an issue describing the change
2. If it's a term addition, include:
   - The term or phrase
   - Which industry it belongs to
   - Why it's considered greenwashing (with sources if possible)
   - The category it fits into

### For Larger Changes

1. Open an issue first to discuss the change
2. Fork the repository
3. Create a branch for your changes
4. Make your changes with clear commit messages
5. Submit a pull request referencing the issue

### For Term Additions

When suggesting new terms, please include:
- The specific term or phrase
- The industry (Food, Beauty/Cosmetics, Fashion, Electronics, Home Goods, Automotive)
- The category (vague terms, misleading claims, etc.)
- Optional: A brief rationale or source explaining why it's problematic

## Code Style

- Keep code simple and readable
- Follow existing patterns in the codebase
- Add comments for complex logic
- Include docstrings for functions
- Use meaningful variable names

## Testing

If you add new functionality:
- Add tests to the `tests/` directory
- Ensure existing tests still pass
- Keep tests simple and maintainable

## What to Expect

- **Response time**: Since this is a side project, responses may take a few days
- **Acceptance criteria**: Changes should align with the tool's educational purpose and maintain simplicity
- **Tone**: Let's keep discussions respectful and constructive

## Questions or Suggestions?

Feel free to open an issue even if you're not sure about something. Questions and suggestions are welcome, and they often lead to valuable improvements.

## A Note on Scope

This tool is intentionally limited in scope to remain maintainable as a student project. Not all features or suggestions may be implemented, but all thoughtful contributions are appreciated and considered.

Thank you for helping make this tool more useful for raising awareness about greenwashing! Every contribution, no matter how small, helps make corporate environmental communication more transparent.
